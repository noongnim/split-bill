# 같이정산

메뉴마다 비용을 나눌 사람을 선택하는 모바일 친화적인 정산 웹사이트입니다. 회원가입, 서버 API, 데이터베이스, 유료 서비스 없이 작동합니다.

## 처음 실행하기

1. 컴퓨터에 Python 3을 설치합니다. 이미 설치되어 있다면 건너뛰세요.
2. 이 저장소를 다운로드하거나 Git으로 복제합니다.
3. 터미널에서 `split-bill` 폴더로 이동합니다.
4. 다음 명령을 실행합니다.

   ```sh
   python3 -m http.server 8000
   ```

   Windows에서는 `py -m http.server 8000`을 사용할 수 있습니다.
5. 내 컴퓨터의 브라우저 주소창에 `http://localhost:8000`을 입력합니다.
6. 종료할 때 터미널에서 `Ctrl+C`를 누릅니다.

`index.html`을 더블클릭하는 대신 위 서버를 사용하세요. JavaScript 모듈은 파일을 직접 열면 브라우저 보안 정책으로 차단될 수 있습니다. 이 서버는 파일을 브라우저에 전달하는 용도이며 정산 데이터를 저장하는 백엔드는 아닙니다.

Codex 클라우드에서는 `/workspace/split-bill`에서 실행합니다. 클라우드의 localhost는 내 컴퓨터의 localhost와 다릅니다. 온보딩 화면에서는 웹 미리보기 링크를 제공하지 않으므로 직접 확인하려면 로컬에서 실행하거나 아래 방법으로 배포하세요.

## 사용 방법

1. 나를 포함한 참여자의 이름을 추가합니다. 동명이인은 별명 등으로 구분합니다.
2. 메뉴명, **개당 가격**, 수량을 입력하고 메뉴를 추가합니다.
3. 처음에는 모든 참여자가 선택됩니다. 해당 메뉴를 먹지 않은 사람의 체크를 해제합니다.
4. 오른쪽 또는 화면 아래에서 각자의 정산 금액을 확인합니다.
5. **정산 결과 복사하기**를 누르고 카카오톡 등에 붙여넣습니다. 자동 복사가 차단되면 표시되는 텍스트 상자에서 직접 복사할 수 있습니다.

참여자를 나중에 추가해도 기존 메뉴의 부담자는 자동으로 바뀌지 않습니다. 체크박스로 직접 선택하세요. 참여자를 삭제하면 메뉴의 부담자에서도 제외됩니다. 부담자가 없는 메뉴가 있으면 정산 결과 공유가 중단됩니다. 메뉴 가격을 잘못 입력했다면 해당 메뉴를 삭제하고 다시 추가하세요.

가격은 1~1,000,000,000원, 수량은 1~10,000개의 정수만 받습니다. 소수점 금액, 할인, 음수 금액은 지원하지 않습니다.

## 계산 원칙

각 메뉴의 `개당 가격 × 수량`을 해당 메뉴 부담자 수로 나눕니다. 원 단위 정수 몫을 배분하고 남은 원은 **참여자 등록 순서대로** 1원씩 배분합니다. 메뉴별로 계산하므로 매번 총결제 금액과 개인별 금액 합계가 일치합니다.

예: 10,000원 메뉴를 세 명이 공유하면 3,334원 / 3,333원 / 3,333원입니다. 1원 추가 배분은 메뉴마다 같은 등록 순서를 사용합니다.

## 저장과 개인정보

- `localStorage`는 브라우저 안의 작은 저장 공간입니다. 같은 브라우저·같은 사이트에서 새로고침하거나 다시 방문하면 내역이 복원됩니다.
- 이름과 메뉴 정보는 외부 서버로 전송되지 않습니다. 외부 폰트·분석 도구도 사용하지 않습니다.
- 다른 기기·브라우저·사이트 주소로 자동 동기화되지 않습니다. 시크릿 모드 종료나 브라우저 데이터 삭제 시 사라질 수 있습니다.
- 공용 기기에서는 사용 후 **내역 모두 지우기**를 누르세요. 결과 복사는 텍스트 공유이며 다른 사람이 편집할 수 있는 공유 링크는 아닙니다.

## 테스트

계산 테스트에는 Node.js 24를 사용했습니다. Node.js 설치 후 저장소 폴더에서 실행하세요. `npm install`은 필요하지 않습니다.

```sh
npm test
```

7개 테스트로 개별/공동 메뉴, 수량, 1원 나머지, 0원 부담자, 부담자 누락, 잘못된 입력, 안전한 정수 범위, 여러 조합에서 합계 일치를 검증합니다.

구현 시 Chromium으로 다음 항목도 확인했습니다: 참여자/메뉴 추가·삭제, 체크박스 변경, 저장 후 새로고침, 클립보드 복사, 부담자 누락 시 복사 차단, 전체 초기화, 입력값을 HTML로 실행하지 않는지, 모바일 390px/데스크톱 1280px 가로 넘침 여부. 계산 테스트는 위 명령으로 재실행할 수 있으며, 화면 검증은 다음 순서로 직접 확인할 수 있습니다.

1. 참여자 3명과 10,000원 메뉴를 추가 → 3,334/3,333/3,333원 확인.
2. 부담자를 2명으로 변경 → 5,000/5,000/0원 확인.
3. 새로고침 → 입력과 선택 유지 확인.
4. 결과 복사 후 메모장에 붙여넣기.
5. 모든 부담자 체크 해제 → 복사 버튼 비활성화 확인.
6. 전체 삭제 후 새로고침 → 빈 내역 확인.

## 무료 배포: GitHub Pages

GitHub Pages는 HTML·CSS·JavaScript 파일을 웹사이트로 공개하는 정적 호스팅입니다. 공개 저장소는 무료로 사용할 수 있습니다.

1. GitHub의 `noongnim/split-bill` 저장소에 이 파일들을 커밋하고 업로드(push)합니다. `main`의 루트에 `index.html`, `style.css`, `app.js`, `calculator.js`가 있어야 합니다.
2. GitHub 저장소에서 **Settings → Pages**로 이동합니다.
3. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
4. Branch를 **main**, 폴더를 **/ (root)**로 선택하고 저장합니다.
5. 배포가 완료되면 Pages 설정에 표시되는 HTTPS 주소로 접속합니다. 해당 화면의 주소를 카카오톡으로 공유할 수 있습니다.
6. 배포된 사이트에서도 위 수동 테스트를 진행하세요. 코드를 수정한 뒤 다시 push하면 배포가 갱신됩니다.

현재 작업에서는 원격 push나 공개 배포를 실행하지 않았습니다. 클라우드 개발 환경의 Publish와 GitHub Pages 배포는 별개입니다.

## 파일 구성과 알아두면 좋은 개념

- `index.html`: 화면에 들어갈 내용과 입력칸을 정의합니다.
- `style.css`: 색상, 간격, 모바일 배치 등 화면 모양을 정합니다.
- `app.js`: 버튼과 체크박스 반응, 브라우저 저장, 결과 복사를 처리합니다.
- `calculator.js`: 화면과 분리된 금액 계산 로직입니다.
- `tests/calculator.test.js`: 계산을 자동 검증합니다.
- `package.json`: `npm test` 같은 개발 명령을 정의합니다. 외부 의존성은 없습니다.

**반응형**은 화면 너비에 맞춰 배치를 바꾸는 방식입니다. **정적 웹사이트**는 서버에서 계산하지 않고 전달받은 파일을 브라우저가 실행하는 사이트입니다. **커밋**은 코드 변경을 기록하는 것이고, **push**는 그 기록을 GitHub에 올리는 것입니다.

## 첫 버전과 향후 개선

구현 완료: 참여자 추가/삭제, 메뉴 가격·수량 등록/삭제, 메뉴별 부담자 선택, 정확한 원 단위 계산, 결과 텍스트 복사, 자동 저장, 반응형 화면.

향후 선택 사항: 메뉴 직접 수정, 여러 모임 저장, 영수증 이미지 인식, 할인·팁 처리, 송금 안내, 공유 링크와 공동 편집. 공유 링크·기기 간 동기화는 서버나 저장 서비스가 필요할 수 있어 첫 버전에서는 제외했습니다.
